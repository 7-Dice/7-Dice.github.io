# ポートフォリオ公開サイト  
- HTML/CSS/JSを用いて製作するサイト  
- Webデザイン  
- Git・Githubによるバージョン管理  
- GithubFlowを用いた開発手法の習得  

## 公開サイト  
**URL:** [https://7-dice.github.io/](https://7-dice.github.io/)    
GithubPagesを利用して製作しています  
## 使用技術・開発環境  
- フロントエンド…HTML5、CSS3、JavaScript  
- 開発環境…EclipseIDE  
- バージョン管理…Git/GitHub  
- 開発フロー…GitHub Flow  
- ホスティング…GitHub Pages    

## 開発・バージョン管理  
開発にはGitHubFlowを採用しています。    
バージョン番号は[Semantic Vaersioning](https://semver.org/lang/ja/)を参考に管理し、リリース時にはGitタグとGitHub Releasesを利用します。  

## 変更履歴・リリース情報  
各バージョンの変更履歴は、Keep a Changelogを参考にCHANGELOG.mdで管理しています。  

- **[CHANGELOG.md](https://github.com/7-Dice/7-Dice.github.io/blob/main/CHANGELOG.md)** バージョンごとの変更内容
- **[GitHub Releases](https://github.com/7-Dice/7-Dice.github.io/releases)** リリースノート・Gitタグ・ソースコード
